# Claude Code Prompt：估價單 AI 擷取工具

> 幫我做一個 Windows 桌面應用程式，最後打包成單一 .exe 執行檔，雙擊就能用，不需要安裝任何環境。

## 功能

1. 開啟後彈出資料夾選擇視窗，選一個資料夾
2. 遞迴掃描該資料夾內所有檔案（含子目錄），支援 PDF、Excel（.xlsx/.xls/.csv）、掃描圖片（.jpg/.png）
3. 每份檔案透過 Anthropic API（Claude）做 AI 智慧擷取，自動辨識不同廠商估價單的欄位名稱差異
4. 所有擷取結果合併輸出成一份 Excel 檔（.xlsx），欄位順序如下：

| 欄位 | 說明 |
|---|---|
| 案件工號 | 留空（保留欄位） |
| 公共工程編碼 | 從文件擷取，若無則空白 |
| 設備名稱 | 從文件擷取（品項/品名/項目名稱等都算） |
| 設備類別 | 從文件擷取，若無則依設備名稱智慧推判（冰水主機→空調） |
| 狀態 | 留空（保留欄位） |
| 建築類別 | 留空（保留欄位） |
| 位置 | 填案件名稱（從估價單表頭抓工程名稱/案名） |
| 廠牌 | 從文件擷取 |
| 型號 | 從文件擷取 |
| 供應商 | 從文件擷取（通常在估價單表頭的公司名稱） |
| 單位 | 從文件擷取 |
| 單價 | 從文件擷取（純數字） |
| 規格細項 | 從文件擷取（所有技術參數） |
| 安裝日期 | 留空（保留欄位） |
| 驗收日期 | 留空（保留欄位） |
| 備註 | 從文件擷取，若無則空白 |

## 技術要求

- Python，用 tkinter 做簡單 GUI（選資料夾、顯示進度、完成後開啟 Excel）
- 用 anthropic SDK 呼叫 Claude API（model: claude-sonnet-4-20250514）
- PDF 讀取用 PyMuPDF（fitz），Excel 用 openpyxl，圖片用 base64 直接傳給 API
- 輸出 Excel 用 openpyxl，表頭加粗、欄寬自動調整、數字欄位格式化
- API key 第一次使用時彈出輸入框，存到使用者目錄的 config 檔，之後自動讀取
- 處理過程顯示進度條（第 X/Y 個檔案、目前檔名）
- 最後用 PyInstaller 打包成單一 .exe（--onefile）
- 輸出的 Excel 存在跟來源資料夾同一層，檔名為「擷取結果_YYYYMMDD_HHMMSS.xlsx」
